# TTSPython 5.1 against 5.0: measured

Every number below was measured on the same PC (Intel i5-12600K, Windows 11), with 5.0.0's code and 5.1's code
run the same way, taking turns, with empty settings and data folders. Lower is better unless the row says otherwise.

## Starting and waiting

| What | 5.0.0 | 5.1 | Change | How |
|---|---|---|---|---|
| Packaged app: window shown | 564 ms | 492 ms | 13% faster | the zip of each, 10 starts each, median |
| From source: window shown | 1021 ms | 899 ms | 12% faster | 10 starts each, median |
| From source: Play ready (voices listed) | 1314 ms | 1168 ms | 11% faster | 10 starts each, median |
| Memory of its own when idle (USS) | 80.3 MB | 72.0 MB | 8.3 MB less | 30 s after start, 4 starts each |
| Memory in all (RSS) when idle | 146.8 MB | 137.5 MB | 9.3 MB less | same |
| Processor use when idle | 0.21% of a core | 0.18% | 14% less | same |
| Wake-ups when idle | 44 a second | 22 a second | half | same |

## Speaking

| What | 5.0.0 | 5.1 | Change | How |
|---|---|---|---|---|
| Stop: time the button takes (median) | 0.11 to 0.14 ms | 0.05 ms | about twice as fast | 6 stops each, 4 runs, real SAPI voice into a silent stand-in device |
| Stop with a slow speech engine | up to 2 s | returns at once | | see the 5.1.0 changelog |
| First sound after Play | 18 to 25 ms | 19 to 25 ms | the same | 6 sentences each, 4 runs |

## Dictating

Stop-to-text: the time from pressing stop to the text being typed. A SAPI voice says "Please remember to buy milk and
eggs on the way home today." into a stand-in microphone in real time, then stays quiet for the pause, then Stop.
Whisper Small, 8 dictations each after one to load the model; every text came out right in both versions.

| Pause before Stop | 5.0.0 median (slowest) | 5.1 median (slowest) |
|---|---|---|
| With the instant preview (the default), 0.5 s | 334 ms (406) | 120 ms (334) |
| With the instant preview, 1.5 s | 441 ms (604) | 5 ms (6) |
| With the instant preview, 3 s | 115 ms (421) | 9 ms (11) |
| Whisper only, 0.5 s | 1311 ms (1328) | 1285 ms (1331) |
| Whisper only, 3 s | 872 ms (1099) | 6 ms (7) |

Talking right up to the stop leaves something for Whisper to check, which takes one pass (about 1.3 s with Small) in
both versions.
